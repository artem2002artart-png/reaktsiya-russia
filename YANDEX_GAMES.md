# РЕАКЦИЯ 8.0 — сборка для Яндекс Игр

Рабочая копия находится в ветке `yandex-games`. Исходная ветка `main` не изменялась.

## Что подготовлено

- Подключён официальный Yandex Games SDK через относительный путь `/sdk.js` (для архива, загружаемого в Консоль разработчика).
- Добавлена инициализация SDK через `YaGames.init()`.
- Добавлено автоопределение языка через `ysdk.environment.i18n.lang`. Эта сборка содержит русские тексты; для неподдерживаемого языка используется русский fallback. В черновике укажите только русский язык.
- Добавлен вызов `LoadingAPI.ready()` после подготовки интерфейса.
- Добавлена разметка игрового процесса через `GameplayAPI.start()` и `GameplayAPI.stop()`.
- Добавлена реакция на события `game_api_pause` и `game_api_resume`; таймер и движение мишени приостанавливаются, когда игра теряет фокус.
- Удалён VK Bridge и ссылка на VK Mini App.
- Ссылка-приглашение теперь строится от текущего адреса игры.
- Локальное сохранение прогресса через localStorage сохранено.

## Загрузка в Яндекс Игры

1. Откройте ветку `yandex-games` и скачайте её как ZIP.
2. Проверьте, что `index.html` находится прямо в корне архива.
3. Не добавляйте в архив SDK-файл: Яндекс предоставляет его по пути `/sdk.js`.
4. В Консоли разработчика Яндекс Игр создайте черновик и загрузите ZIP.
5. В поле локализаций укажите русский язык, так как эта сборка пока не переведена на другие языки.
6. Откройте игру с debug-панелью и проверьте индикаторы SDK, Game Ready, языка и Gameplay.

## Что ещё нужно проверить перед публикацией

- Пройти игру в черновике Яндекс Игр на компьютере и мобильном устройстве.
- Проверить сохранение прогресса после перезагрузки.
- Проверить отсутствие ошибок в DevTools.
- Подготовить карточку игры: название, описание, иконку, обложку и скриншоты.
- Рекламные блоки и таблица лидеров Яндекса пока не подключены. Их можно добавить отдельно после базового тестирования.
