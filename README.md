# РЕАКЦИЯ — российская версия

Отдельная копия исходного проекта для подготовки российской версии игры.

## Важно
- Этот репозиторий отделён от международного репозитория `Arkada`.
- Копирование исходного кода само по себе не переносит базу данных и не меняет место обработки персональных данных.
- Перед публикацией российской версии нужно отдельно проверить backend, хранение данных, политику конфиденциальности и требования платформы.
- Секретные ключи нельзя добавлять в клиентский `index.html` или коммитить в Git.

## Исходная копия
Файл `index.html` скопирован из `artem2002artart-png/Arkada`, ветка `main`.
