# РЕАКЦИЯ — российская версия

**РЕАКЦИЯ** — браузерная аркадная игра на скорость реакции. Игрок нажимает на появляющуюся мишень, набирает очки, собирает комбо и улучшает личные результаты.

## Запуск игры

Открой опубликованную версию:
https://artem2002artart-png.github.io/reaktsiya-russia/

Игра запускается в браузере. Отдельная установка не требуется.

## Возможности

- Игровые раунды с выбором сложности.
- Подсчёт очков, комбо и личного рекорда.
- Монеты и магазин игровых оформлений.
- Профиль игрока, уровни и опыт.
- Ежедневная награда и ежедневные задания.
- Достижения.
- Локальное сохранение игрового прогресса в браузере.

## Хранение данных

На текущем этапе игра работает без онлайн-таблицы рекордов и без подключения к Supabase. Игровой прогресс хранится локально в браузере пользователя (localStorage). Поэтому данные не синхронизируются между разными устройствами или браузерами и могут быть потеряны при очистке данных сайта.

Возможность добавить общий онлайн-рейтинг через российскую инфраструктуру рассматривается как следующий этап развития проекта.

## Технологии

- HTML
- CSS
- JavaScript
- localStorage
- VK Bridge (для интеграции с платформой ВКонтакте)

## Разработка и публикация

Исходный код игры находится в файле `index.html`. Публикация выполняется через GitHub Pages из ветки `main`.

## Важные замечания перед выпуском

Перед отправкой на модерацию необходимо отдельно проверить работу игры в WebView ВКонтакте, все игровые кнопки, сохранение прогресса, адаптацию под мобильные экраны, а также требования платформы к описанию, обработке данных и политике конфиденциальности.

Секретные ключи и пароли нельзя размещать в клиентском коде или коммитить в Git.
